# Service System: локальный плагин

Плагин для настольного клиента с поддержкой локальных MCP-серверов. Читает
завершённые отчёты, историю объекта, существующие дефекты и сохраняет предложения
с цитатами. Пользователь создаёт дефекты кнопкой подтверждения в программе.
Фотографии и отметки проверки обрабатываются в самой программе.

Плагин не вызывает OpenAI API и не требует API-ключа. Анализ выполняет модель
чата в пределах доступа и лимитов клиента. Это не автономный GPT внутри сайта.
Подключение к веб-версии ChatGPT потребует отдельного удалённого MCP-сервера
с OAuth; данный stdio-плагин для неё не предназначен.

## Установка на этом компьютере

Из корня репозитория:

```sh
python3 -m venv plugin/.venv
plugin/.venv/bin/python -m pip install -r plugin/requirements.txt
plugin/.venv/bin/python plugin/scripts/configure.py
```

Настройте локальный источник плагинов в настольном клиенте на этот репозиторий
(описание источника находится в `.claude-plugin/marketplace.json`) и установите
Service System. Если клиент принимает только конфигурацию MCP, используйте
сгенерированный `plugin/.mcp.json`. Файл содержит абсолютные пути этого
компьютера и поэтому не включается в Git.

В программе откройте «Итоги выездов → Подключение к чату», создайте подключение
и скачайте файл. Затем установите его, указав путь к скачанному файлу:

```sh
plugin/.venv/bin/python plugin/scripts/configure.py ~/Downloads/service-system-connection.json
```

Перезапустите подключение плагина в клиенте. Удалённый адрес должен использовать
HTTPS. Ключ действует 30 дней, ограничен отчётами и предложениями и отзывается
в том же разделе программы. Он не позволяет создавать дефекты, менять выезды,
удалять данные или управлять пользователями. Изменение прав владельца также
прекращает доступ. Файл с ключом не загружать в чат, GitHub или общий диск.

Пример запроса: «Проверь завершённые выезды с 2026-09-01 по 2026-09-30,
найди неустранённые неисправности и подготовь предложения дефектов».
