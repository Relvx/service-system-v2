# Печать расписания на месяц

**Дата:** 2026-04-17

## Цель

Из раздела «Расписание» по клику формируется таблица для печати: клиенты, которых обслуживаем в выбранном месяце, с пометками расписания и итогами последних выездов.

## Данные

Таблица содержит строку на каждый договор с активным расписанием в выбранном месяце.

**Столбцы:**
- `#` — порядковый номер
- `Клиент` — `client_name`
- `Договор` — `contract_number`
- `Пометки` — `note` из ячейки расписания (например, «ТО+доки»)
- `Последние выезды` — до 3 завершённых выездов: дата + `work_summary`

**Источники данных:**
1. `GET /schedule/month?year=Y&month=M` → список договоров с пометками
2. `GET /visits?contract_id=X&status=done&limit=3` — параллельно для каждого договора

## Маршрут и компонент

**Новый роут:** `/print/schedule/:year/:month`
- Добавляется в `router/index.js`
- Не требует изменений в auth guard (открывается в браузере с уже активной сессией)

**`PrintSchedulePage.vue`:**
- Без `<Layout>` — только чистая страница с таблицей
- `onMounted`: запрос расписания → `Promise.all` запросов выездов → рендер → `window.print()`
- Пока данные грузятся — спиннер (печать не запускается до готовности)
- Шапка: «Расписание на [Месяц] [Год]» + «Сформировано: дд.мм.гг»
- Подвал: «Всего: N договоров»
- Кнопка «Закрыть» — скрывается через `@media print`

**CSS:**
```css
@page { size: A4 landscape; margin: 15mm; }
@media print { .no-print { display: none; } }
```

## Кнопка запуска

В `SchedulePage.vue` — новая кнопка «Распечатать месяц» (иконка `Printer`) в шапке, доступна в обоих режимах (год и месяц):

```js
function printMonth() {
  const y = currentYear.value
  const m = viewMode.value === 'month' ? currentMonth.value : new Date().getMonth() + 1
  window.open(`/print/schedule/${y}/${m}`, '_blank')
}
```

```
──────────────────────────────────────────────────────────────────────
 №  | Клиент          | Договор    | Пометки   | Последние выезды
────┼─────────────────┼────────────┼───────────┼──────────────────────
 1  | ООО Ромашка     | №123/2024  | ТО+доки   | 10.03.26 — Выполнено ТО
    |                 |            |           | 15.01.26 — Плановое ТО
────┼─────────────────┼────────────┼───────────┼──────────────────────
 2  | ИП Петров       | №45/2023   | ТО+бух    | 02.02.26 — ТО пройдено

Всего: 2 договора
```

- Ориентация: **альбомная** (A4 landscape)
- Каждый выезд — отдельная строка: `дд.мм.гг — итог работ`
- Если `work_summary` пуст — только дата
- Если пометки нет — ячейка пустая
